Saisissez un nom, un prénom ou une organisation dans la barre de recherche pour consulter une fiche.

Configuration du mapping

Associez les champs de la fiche aux colonnes de vos tables Grist. Les champs facultatifs peuvent rester non associés.

1. Tables sources

2. Champs de la fiche contact

3. Correspondance avec les organisations

La colonne « Organisation » dans Contacts doit contenir la référence Grist vers l'organisation. Pour la clé de correspondance, choisissez « Identifiant interne Grist (id) » si la colonne est une référence Grist standard ; sinon choisissez la colonne contenant la clé correspondante.

Les choix sont enregistrés dans les options de cette instance du widget. Le widget lit les données mais ne les modifie pas.
